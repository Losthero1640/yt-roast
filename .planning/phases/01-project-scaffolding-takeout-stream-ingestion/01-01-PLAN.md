<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Fastify Stream | Untrusted client provides arbitrary JSON upload. Could be huge, truncated, or malicious. |
| Stream -> Memory Heap | Streaming JSON parser converts raw bytes into JS objects. High token volume could trigger OOM if not bounded. |

## Threat Analysis

| Threat ID | Component | Vulnerability | Severity | Mitigation |
|-----------|-----------|---------------|----------|------------|
| T-01-01 | Takeout Stream Parser | Memory exhaustion via massive JSON array | High | Incremental StreamArray parsing under Node.js backpressure; discard raw items immediately; never buffer full history. |
| T-01-02 | Multipart Ingestion | Disk exhaustion via temporary spooling | High | Explicit Fastify multipart config { attachFieldsToBody: false } and zero disk-temp adapters; direct stream pipe. |
| T-01-03 | Takeout Stream Parser | DoS / CPU exhaustion via malformed JSON or infinite stream | Medium | Fast-fail on syntax error; 100MB body limit; stream destroyed on error. |
| T-01-04 | Demo Profile Loader | PII leak in demo data | Low | Fixtures are 100% synthetic, verified to contain zero real user IDs, emails, or personal names. |
</threat_model>
