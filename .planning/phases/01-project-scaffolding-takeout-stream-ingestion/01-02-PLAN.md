<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Normalizer -> Scoring | Untrusted data from stream feeds into scoring algorithms. NaN / Infinity or missing values could corrupt calculation. |
| Ingestion -> OS Filesystem | Untrusted file upload could trigger disk caching if middleware or temp spoolers are engaged. |

## Threat Analysis

| Threat ID | Component | Vulnerability | Severity | Mitigation |
|-----------|-----------|---------------|----------|------------|
| T-01-05 | Brainrot Calculator | Division by zero or NaN propagation from empty/sparse datasets | High | Explicit threshold guards (<20 records aborts); Math.max(0, min(100, ...)) clamping; NaN-safe fallback. |
| T-01-06 | Ingestion Pipeline | Covert disk buffering via temp files | Critical | Multi-layer test verification asserting 0 fs write API calls + snapshot verification of os.tmpdir(). |
| T-01-07 | Normalizer Memory | Heap leak via unbounded title/creator map growth | Medium | Ingestion bounded to 100MB; maps track only string primitives; raw objects dereferenced immediately. |
</threat_model>
