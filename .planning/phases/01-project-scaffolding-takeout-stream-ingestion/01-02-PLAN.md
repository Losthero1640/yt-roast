  <name>Task 2: Implement Deterministic Brainrot Scoring Engine & Renormalization Matrix</name>
  <files>src/scoring/brainrot-calculator.js, tests/unit/scoring.test.js</files>
  <behavior>
    - D-01: Calculate explicit 0–100 subscores using exact baseline-shifted formulas:
      * Late-Night Subscore (S_late):
        R_late = (lateNightViews 12 AM–5 AM) / validTimestampViews
        If R_late <= 0.05: S_late = 0 (baseline).
        If R_late >= 0.25: S_late = 100 (ceiling).
        Otherwise: S_late = min(100, max(0, round(((R_late - 0.05) / 0.20) * 100))).
      * Creator Dominance Subscore (S_creator):
        C_top5 = (views in top 5 creators) / totalValidVideos
        If C_top5 <= 0.15: S_creator = 0.
        If C_top5 >= 0.50: S_creator = 100.
        Otherwise: S_creator = min(100, max(0, round(((C_top5 - 0.15) / 0.35) * 100))).
      * Title Replay Subscore (S_title):
        T_rep = totalReplayEvents / totalValidVideos
        If T_rep <= 0.02: S_title = 0.
        If T_rep >= 0.12: S_title = 100.
        Otherwise: S_title = min(100, round((T_rep / 0.12) * 100)).
      * Combined Repetition Subscore (S_rep):
        S_rep = round((S_creator * 20 + S_title * 15) / 35).
      * Watch Velocity Subscore (S_vel):
        V_cluster = rapidFireCount / (validTimestampViews - 1)
        If V_cluster <= 0.15: S_vel = 0.
        If V_cluster >= 0.60: S_vel = 100.
        Otherwise: S_vel = min(100, max(0, round(((V_cluster - 0.15) / 0.45) * 100))).
    - D-02: Map final composite score to 5 comedic tiers:
      * 0–19: Monk
      * 20–44: Casual
      * 45–69: Slime Brain
      * 70–89: Deep Fried
      * 90–100: Digital Zombie
    - D-03: Execute exact 4-case missing data renormalization matrix:
      * Case A (Full Data: validRecords >= 20, validTimestamps >= 20, intervals >= 2):
        Score = round(S_late * 0.35 + S_rep * 0.35 + S_vel * 0.30). Confidence: "high".
      * Case B (Degraded Timestamps: validRecords >= 20, but validTimestamps < 20 or >50% missing):
        S_late = null, S_vel = null. Score = S_rep (100% weight). Confidence: "low".
        degradedNotice: "Score calculated on creator and title repetition only; time metrics unobserved."
      * Case C (No Intervals: validRecords >= 20, validTimestamps >= 20, but rapid intervals < 2):
        S_vel = null. Score = round(S_late * 0.50 + S_rep * 0.50). Confidence: "medium".
        degradedNotice: "Session velocity omitted due to isolated timestamps."
      * Case D (Sparse Data: validRecords < 20):
        Score = null. Tier = "Unranked". Confidence: "low". isInsufficient = true.
  </behavior>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Normalizer -> Scoring | Untrusted data from stream feeds into scoring algorithms. NaN / Infinity or missing values could corrupt calculation. |
| Ingestion -> OS Filesystem | Untrusted file upload could trigger disk caching if middleware or temp spoolers are engaged. |

## Threat Analysis

| Threat ID | Component | Vulnerability | Severity | Mitigation |
|-----------|-----------|---------------|----------|------------|
| T-01-05 | Brainrot Calculator | Division by zero or NaN propagation from empty/sparse datasets | High | Explicit threshold guards (<20 records aborts); Math.max(0, min(100, ...)) clamping; NaN-safe fallback. |
| T-01-06 | Ingestion Pipeline | Covert disk buffering via temp files | Critical | Multi-layer test verification asserting 0 fs write API calls + snapshot verification of os.tmpdir(). |
| T-01-07 | Normalizer Memory | Heap leak via unbounded title/creator map growth | Medium | Ingestion bounded to 100MB; maps track only string primitives; raw objects dereferenced immediately. |
</threat_model>
