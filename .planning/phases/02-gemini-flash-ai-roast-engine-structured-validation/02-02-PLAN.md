<task id="02-02-01" wave="2">
<title>Define domain error hierarchy for AI generation & privacy</title>
<description>
Create `src/ai/errors.js` defining custom domain error classes:
1. `ConsentRequiredError`: Thrown when `consentGranted !== true`.
2. `GeminiTimeoutError`: Thrown when generation exceeds 15,000 ms.
3. `GeminiRateLimitError`: Thrown on HTTP 429 / resource exhaustion with user-friendly retry timing.
4. `GeminiValidationError`: Thrown on unparseable JSON, schema validation failure, or evidence hallucination.
5. `GeminiServiceError`: Thrown on upstream 5xx or unhandled network errors.
Ensure all error classes defensively sanitize messages to ensure API keys, full prompts, and user viewing evidence are never attached to error properties or stack traces.
</description>

<task id="02-02-02" wave="2">
<title>Implement RoastGeneratorService with @google/genai, structured output, and timeout cancellation</title>
<description>
Create `src/ai/roast-generator-service.js` implementing:
1. Class `RoastGeneratorService`:
   - Constructor accepting optional `{ apiKey, model, client }` for dependency injection during testing.
   - Defaults: `apiKey: process.env.GEMINI_API_KEY`, `model: process.env.GEMINI_MODEL || 'gemini-2.5-flash'`.
   - Client: Instantiates `new GoogleGenAI({ apiKey, httpOptions: { timeout: 15000 } })`.
2. Method `generateRoastReport({ profile, scoreResult, consentGranted })`:
   - Step 1 (Consent Gate): Asserts `consentGranted === true`; throws `ConsentRequiredError` if false or undefined.
   - Step 2 (Prompt Assembly): Calls `buildRoastPrompt({ profile, scoreResult })`.
   - Step 3 (Abort Signal Setup): Creates `AbortController` and starts a 15,000 ms timer.
   - Step 4 (Gemini Structured Call): Calls `ai.models.generateContent` with:
     - `model: this.model`
     - `contents: prompt`
     - `config: { responseMimeType: 'application/json', responseSchema: ..., abortSignal: controller.signal }`
   - Step 5 (JSON Parsing & Score Immutability):
     - Parses `response.text`.
     - Overrides `parsed.brainrotScore = scoreResult.score`.
     - Overrides `parsed.cardPayload.brainrotScore = scoreResult.score`.
     - Overrides `parsed.cardPayload.tier = scoreResult.tier`.
   - Step 6 (Schema & Grounding Validation):
     - Validates against `EnhancedRoastReportSchema`.
     - Validates joke grounding using `validateJokeGrounding(parsed, allowedEvidence)`.
   - Step 7 (Full Result Assembly): Returns `FullRoastResultSchema.parse({ roast: parsed, scoreDetails: scoreResult })`.
   - Step 8 (Resilient Error Mapping): Catches timeouts, 429s, validation errors, and network errors, re-throwing sanitized domain error classes.
   - Clean up timeout timer in `finally` block.
</description>
