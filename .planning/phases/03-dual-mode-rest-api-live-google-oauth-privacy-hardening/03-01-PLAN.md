<task id="03-01-01" wave="1">
<title>Implement sanitized logger, error handler, and no-store security headers</title>
<description>
Create `src/utils/logger.js` and `src/utils/error-handler.js`:
1. `src/utils/logger.js`:
   - Redacts authorization codes, OAuth tokens, client secrets, and file content payloads from logged output across all log levels per `PRIV-04`.
2. `src/utils/error-handler.js`:
   - Fastify error handler mapping domain errors to appropriate HTTP statuses:
     - `ConsentRequiredError` -> 400 Bad Request
     - `PayloadTooLargeError` / multipart FST_REQ_FILE_TOO_LARGE -> 413 Payload Too Large
     - `TakeoutParseError` -> 400 Bad Request
     - `GeminiRateLimitError` -> 429 Too Many Requests
     - `GeminiTimeoutError` -> 504 Gateway Timeout
     - `GeminiValidationError` -> 502 Bad Gateway
     - Generic / unhandled errors -> 500 Internal Server Error
   - Sanitizes response payload: returns standard structured `{ error: { code, message } }`.
   - Strips stack traces, filesystem paths, authorization codes, OAuth tokens, and raw file line snippets per `SEC-02`.
3. In `src/app.js`:
   - Register an `onSend` hook for `/api/roast/*` routes injecting `Cache-Control: no-store, private, max-age=0`, `Pragma: no-cache`, and `Surrogate-Control: no-store` per `SEC-01`.
   - Attach global error handler using `app.setErrorHandler(...)`.
</description>

<task id="03-01-02" wave="1">
<title>Implement health, demo, and streaming upload routes</title>
<description>
Create `src/routes/health.js` and `src/routes/roast.js`:
1. `src/routes/health.js`:
   - `GET /api/health`: Returns service status, uptime, and storage verification metadata (`zero-persistence-in-memory`).
2. `src/routes/roast.js`:
   - `GET /api/roast/demo`: Returns the pre-computed "The 3 AM Productivity Goblin" demo roast immediately via `loadDemoProfile()`.
   - `POST /api/roast/upload`:
     - Checks consent query parameter or multipart field `consent === 'true'`. If missing, throws `ConsentRequiredError` (`API-05`).
     - Reads file stream via `req.file()`. Enforces 100MB max file size limit; Fastify automatically triggers 413 without buffering excess bytes (`API-02`).
     - Direct in-memory stream pipeline: pipes stream into `parseTakeoutStream(file.file, sink)` and `TakeoutNormalizer` without temporary disk files (`PRIV-02`).
     - If dataset has fewer than 20 valid records, returns honest fallback message per `NORM-05` without calling Gemini.
     - Calculates deterministic Brainrot score via `calculateBrainrotScore(profile)`.
     - Generates roast report via `roastGeneratorService.generateRoastReport({ profile, scoreResult, consentGranted: true })`.
     - Returns HTTP 200 with `FullRoastResult` payload.
</description>
