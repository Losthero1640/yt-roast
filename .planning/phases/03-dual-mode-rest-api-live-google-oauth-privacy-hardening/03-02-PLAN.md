<title>Implement Mode 1 Google OAuth service with zero token persistence</title>
<description>
Create `src/oauth/google-oauth-service.js` and `fixtures/mock-oauth-data.js`:
1. `src/oauth/google-oauth-service.js`:
   - Reads credentials from `process.env.GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI`.
   - `getAuthorizationUrl({ state })`: Constructs Google OAuth authorization URL requesting scope `https://www.googleapis.com/auth/youtube.readonly` with `access_type=online`.
   - `exchangeCodeForToken(code)`: Uses lightweight native `fetch` to exchange code at `https://oauth2.googleapis.com/token`.
   - `fetchUserTasteProfile(accessToken)`: Fetches user's subscriptions and liked videos via YouTube Data API v3 (`/subscriptions` and `/videos`).
   - Ephemeral token lifecycle: Drops `accessToken` immediately after API retrieval. Never persists token to session, database, or disk (`API-03`).
   - Adapts subscriptions and liked videos into a `NormalizedViewingProfile` (top subscribed channels mapped to `topCreators`, liked titles mapped to `repeatedTitles`).
   - Computes deterministic score and generates roast via `RoastGeneratorService`.
   - Attaches mandatory Mode 1 disclaimer badge (`API-04`):
     `"disclaimer": "This roast is based solely on your public subscriptions and liked videos, not complete viewing history."`
2. `fixtures/mock-oauth-data.js`:
   - Provides realistic synthetic fixtures for YouTube `subscriptions.list` and `videos.list` (liked videos) for deterministic testing without live credentials.
3. Wire OAuth routes in `src/routes/roast.js`:
   - `GET /api/roast/oauth/url`: Returns `{ url }`.
   - `GET /api/roast/oauth/callback`: Validates code, executes Quick Roast, and returns report with disclaimer badge.
</description>
